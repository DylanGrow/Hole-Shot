# 🕳️ Hole Shot

**The Ultimate Backyard Game Scoring Engine.**

Hole Shot is a high-performance, premium web application designed for competitive backyard athletes. Whether you're playing Cornhole, Horseshoes, or Washers, Hole Shot provides a state-of-the-art scoring interface with voice control, all-time statistics, and cinematic visuals.

![Hole Shot Preview](https://raw.githubusercontent.com/psdgr/hole-shot/main/public/preview.png)

## ✨ Key Features

- **🎙️ Voice Command Scoring**: Keep your hands on the bags. Score with your voice ("Team A three", "Team B one", "Undo").
- **🏆 Hall of Fame**: Advanced player tracking that remembers every legend who has played and ranks them in a global leaderboard.
- **⚔️ Rivalry Series**: Automatic head-to-head tracking that shows the historical series record between any two teams.
- **📸 Victory Export**: Generate high-resolution (1200x630) championship cards of your wins to share on social media.
- **👴 Trash-Talking Uncle**: Integrated voice synthesis that provides "feedback" on your performance, especially if you get skunked.
- **📱 PWA & Offline-First**: Works perfectly in the middle of a field with no internet. Save it to your home screen for a native experience.
- **🔒 Privacy First**: Zero trackers, no external fonts, and all data is stored locally in your browser (IndexedDB).

## 🛠️ Tech Stack

- **Framework**: React + TypeScript
- **Styling**: Tailwind CSS + Framer Motion (Spring Physics)
- **State**: Zustand
- **Database**: Dexie.js (IndexedDB)
- **Build**: Vite

## 🚀 Getting Started

1.  **Clone the repo**:
    ```bash
    git clone https://github.com/psdgr/hole-shot.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run locally**:
    ```bash
    npm run dev
    ```
